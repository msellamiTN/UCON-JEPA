## Generated dataset

- 300 episodes per family/policy combination.
- 3 policy families × 3 agent behavior policies = 2,700 episodes.
- Exactly 8 transitions per episode: 21,600 total transitions.
- Context dimension: 34; action dimension: 9; security target dimension: 4.
- Episode-disjoint train/validation/test split.

The three policies create intentionally distinct regimes:
- Goal-directed follows prerequisites visible in the synthetic governance context and incurs no denials in this generator.
- Uniform produces mixed accepted and denied attempts.
- Retrying adversary repeats the privileged terminal action after each denial and therefore has a 100% denial rate by construction.

## Transition and leakage validation

The CI suite passed:
- Every episode has exactly eight transitions, including after DENY.
- Episodes are disjoint across train, validation and test.
- Every policy/family pair appears in test.
- Oracle and online enforcement gate agree on every generated transition.
- DENY preserves protected workflow flags while incrementing attempt history and exposing the denied action in the next context.
- The retrying adversary repeats the last denied action.
- Fixed-seed generation is reproducible.

## Interpretation and limits

G8.4.7 removes the early-stop censoring mechanism from G8.4.3 for this controlled dataset by continuing the agent trajectory after DENY. It makes the horizon populations fixed-length within each generated episode process.

This is not a claim that the synthetic behavior policies represent real agent populations. In particular, the goal-directed policy is supplied the synthetic governance context, and the retrying adversary is deliberately repetitive. The current result is dataset/semantics validation only; no predictive model or performance claim is made in G8.4.7.

The next experiment should test action-policy generalization (including leave-one-policy-out evaluation) and compare:
1. known future action sequence,
2. predicted future action sequence,
3. reactive formal UCON-only baseline.

Formal UCON remains the only authorization authority.
