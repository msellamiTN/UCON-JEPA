# G8.4.7 — Fixed-length policy-conditioned agent trajectories

## Motivation

G8.4.3 stops an episode at the first denied action. G8.4.6 therefore evaluates longer horizons only on episodes that survive long enough to provide a complete window. That is a valid conditional estimand, but it changes the test population with horizon and prevents observation of agent adaptation after denial.

G8.4.7 introduces a separate dataset version. G8.4.3 remains unchanged for reproducibility.

## Transition semantics

- Every episode has a fixed configured length (default 8).
- Each step records the pre-action state, proposed action, post-enforcement state, and security labels.
- On DENY, protected workflow flags do not change.
- Attempt history is incremented and the denied action is exposed as explicit feedback in the next context representation.
- The agent may adapt, choose another action, or repeat the denied action. The episode does not truncate.
- The batch policy oracle and separately coded online gate must agree at every transition.

## Agent behavior policies

1. goal_directed: follows the synthetic workflow prerequisites when governance context permits.
2. uniform: samples from the family action vocabulary without state adaptation.
3. retrying_adversary: proposes the privileged terminal action and repeats it after DENY.

These are deliberately transparent synthetic behavior policies, not claims about real autonomous-agent distributions.

## Data and leakage boundaries

- Context includes current workflow/governance state, action history, prior denial state and one-hot feedback for the last denied action.
- Current action is a separate input.
- Future state and security labels are target-side only.
- Agent-policy identity is retained as a group variable for stratified evaluation and policy-holdout studies.
- All rows of an episode remain in one deterministic train/validation/test partition.

## Required validation

- Fixed episode length for all policies/families.
- No episode overlap across partitions.
- Coverage of every policy/family combination in test.
- Oracle/online-gate agreement for every generated transition.
- DENY leaves protected workflow state unchanged while recording the attempt and feedback.
- Retry policy demonstrably repeats the last denied action.
- Reproducibility under fixed seeds.

## Limits

The data remain synthetic. Goal-directed behavior can inspect the synthetic governance context. The retrying adversary is intentionally repetitive. Fixed-length trajectories eliminate early-stop censoring in this generated process, but they do not make the process representative of real agent behavior. G8.4.7 defines a better controlled substrate; it does not yet establish predictive performance.
