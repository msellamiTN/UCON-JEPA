# G8.4.8.7.8 — Crossed-seed audit of initial-position direction stability

**State:** preregistered protocol; implementation not started  
**Depends on:** G8.4.8.7.5 matched recursive control, G8.4.8.7.6 calibration diagnostics, G8.4.8.7.7 temporal-support alignment  
**Branch:** `research/g8.4.8.7.8-crossed-seed-initial-direction`  
**Scope:** diagnostic only; no architecture, loss, optimizer, data-generation, calibration-method, or authorization changes

## 1. Motivation and research question

The completed G8.4.8.7.7 audit confirmed that fitting a horizon-1 calibrator on trajectory position 0 and applying it to positions 0–7 creates a temporal-support transport mismatch. It also showed a separate unresolved phenomenon: JEPA seed 20261122 has a negative raw score-label relationship at position 0, while positions 1–7 have positive relationships. The matched supervised recursive control did not show the same extreme calibration failure.

The current evidence contains only five diagonal runs in which the dataset-generation seed and model-training seed are identical. Those runs cannot distinguish whether the position-0 failure follows:

1. the generated synthetic dataset / episode sample;
2. the model-training stochasticity (initial weights and minibatch order);
3. a dataset-by-training-seed interaction; or
4. a JEPA-specific effect, rather than a behavior shared with the matched supervised control.

**Primary question:** when dataset generation and model-training randomness are varied independently in a fully crossed design, does the negative initial-position score direction follow the dataset seed, the model-training seed, or neither—and is it specific to JEPA?

This is not a test of a new JEPA architecture and not a claim about real agents.

## 2. Design: fully crossed 5 × 5 seed matrix

Use two independent seed factors:

- Dataset-generation seeds (D = {20261120,20261121,20261122,20261123,20261124}).
- Model-training seeds (M = {20261120,20261121,20261122,20261123,20261124}).

Run every pair ((d,m) in D 	imes M), for **25 dataset/training-seed combinations**. The five existing diagonal combinations ((d=m)) are the prior G8.4.8.7.5–7.7 observations; recompute the complete matrix under one frozen implementation and require the diagonal to reproduce the existing raw position-0 results within a prespecified numerical tolerance. Do not silently reuse old rows if the reproduction check fails.

For each pair:

1. Generate the dataset once with dataset seed (d), using the unchanged G8.4.8.7.1 generator, 300 episodes per archetype × resource-family × rho cell, and the existing train/validation/calibration/shifted-test/reverse-test partitions.
2. Fit JEPA E2 with model-training seed (m).
3. Fit the corrected matched supervised recursive E2 control on the exact same dataset with model-training seed (m).
4. Keep model and optimizer configurations identical to the validated G8.4.8.7.5–7.7 protocol. No hyperparameter tuning or seed exclusion.
5. Hold Monte Carlo rollout randomness fixed across the entire 5 × 5 matrix and both models, independently of both dataset seed d and model-training seed m. For horizon H, define calibration rollout seed = 20261119 + 10,000*H and test rollout seed = 20261119 + 100,000*H + split_offset, where split_offset is 0 for shifted and 500,000 for reverse. This prevents Monte Carlo action-sampling noise from being confounded with either crossed factor. Separately, for the five diagonal reproduction checks only, repeat inference with the legacy per-seed rollout derivation (calibration seed = d + 10,000*H; test seed = d + 100,000*H + split_offset) and compare those vectors with the prior benchmark evidence. Legacy-reproduction predictions do not enter the crossed-matrix analysis.
6. The diagonal reproduction pass uses the same fitted model parameters as the corresponding matrix cell but a separate legacy inference RNG; it must reproduce the previous diagonal position-0 calibration slope and shifted-test raw AUROC, Brier, and score-direction difference within absolute tolerance 1e-12 and zero relative tolerance. The previous artifact does not retain raw per-window prediction vectors, so the check is explicitly against these retained summary metrics, not against unavailable vectors. A failure is a hard validation failure, not grounds to alter the primary matrix or relax tolerance.
6. Run the complete matrix. Do not stop early when a favorable or unfavorable pattern appears.

**Important factor interpretation:** the current NumPy JEPA implementation uses the configured model seed both to initialize weights and to generate minibatch permutations. Therefore (m) is a *combined model-training stochasticity factor*, not a pure initialization-only factor. This design can distinguish data-seed effects from the combined training-seed effect, but cannot attribute a training-seed effect separately to initialization versus minibatch order. A later experiment would need independently controlled RNG streams to separate those components.

The action-head implementation is deterministic given its training/validation inputs and starts from zero weights. Its checkpoint selection and calibration remain unchanged.

## 3. Fixed model and information conditions

- Models: JEPA E2 and the corrected `LinearSupervisedStateDynamics` recursive E2 comparator.
- JEPA latent dimension: 12; supervised latent dimension: 8.
- Preserve the validated near-matched trainable parameter counts and all loss weights, learning rates, batch sizes, EMA settings, epoch budgets, validation checkpoint selection, and action-temperature fitting.
- Horizons: **H=1 primary only**. This stage targets the initial-position failure; no new H2/H4/H8 claim is required.
- Primary temporal support: `start_step == 0` for both calibration and test. No pooled-position evaluation is used for the primary endpoint.
- Monte Carlo rollouts: 32, unchanged.
- Test mixtures: shifted (ho=0.85) primary; reverse (ho=0.05) diagnostic.
- Training rho values, policy archetypes, resource families, episode length, feature construction, scalers, and partition rules remain unchanged.
- E2 inference receives only the initial decision-time context and the model's learned parameters. Future actions are sampled autoregressively by the model-specific past-only action head.

No future action, future observation, future security label, policy metadata, episode ID, split label, or start-position metadata may enter model inference. Such metadata is permitted only for offline calibration partitioning, grouping, and evaluation after predictions have been produced.

## 4. Endpoints and required reporting

### 4.1 Primary endpoint: raw position-0 direction

For each dataset seed × model-training seed × model × test split, use H=1 and position 0 only. Report:

- raw risk AUROC and AUPRC;
- raw Brier and ECE;
- positive-minus-negative mean raw score difference (Delta = ar{s}_{y=1}-ar{s}_{y=0});
- positive/negative score means, standard deviations, quantiles, class counts, prevalence, and number of unique episodes;
- raw score distributions and per-archetype × resource-family breakdowns.

The primary inferential target is the **pattern of direction across the 25 crossed cells**, not a single best metric or a post-hoc selected seed.

### 4.2 Calibration-only direction diagnostic

Fit the unchanged ridge-Platt calibrator using only H=1 calibration windows at `start_step == 0`. Report slope, intercept, score-logit center/scale, convergence status, class counts, and calibration (Delta). Apply the fitted calibrator only to H=1 test windows at `start_step == 0`.

Report calibrated AUROC, AUPRC, Brier and ECE. Do not constrain the slope sign, flip scores, choose a calibrator from test results, or use the shifted/reverse test outcomes to select a model or method.

### 4.3 Matched-control contrasts

For each ((d,m)), compute JEPA-minus-supervised paired differences for:
- raw position-0 AUROC;
- raw position-0 Brier;
- calibration slope and score-direction (Delta);
- calibrated position-0 Brier.

The two models share the same dataset and model-training seed factor, but their model structures and parameter counts remain as in the established matched-control protocol. Report all 25 paired cells, not only their aggregate mean.

### 4.4 Factor-pattern analysis

For each outcome and model, provide:
- a 5 × 5 heatmap/table with dataset seed as rows and model-training seed as columns;
- row means (dataset-seed marginal patterns);
- column means (training-seed marginal patterns);
- full cell residuals after removing row and column means;
- direction-failure counts by dataset seed and by model-training seed;
- JEPA-versus-supervised paired cell contrasts.

A two-way additive decomposition may summarize dataset-seed and training-seed main-effect patterns. With one observation per cell, dataset × training interaction is confounded with residual cell variation and **must not be reported as an independently estimated variance component**. With only five levels per factor, all factor summaries are descriptive and exploratory; do not claim population-level variance estimates or causal mechanism identification.

### 4.5 Uncertainty

- Retain all episode-level position-0 predictions and labels for reproducibility.
- For each cell, compute 2,000 stratified whole-episode percentile-bootstrap replicates separately on calibration position-0 windows and on the primary shifted-test position-0 windows. The reverse split is descriptive only and does not receive a second bootstrap. Resample episode IDs with replacement within the observed archetype × family × binary-label strata (up to 30 strata), preserving each stratum's observed episode count. This guarantees both classes remain represented wherever both classes exist in a source stratum, but makes the intervals conditional on observed class counts; do not interpret them as prevalence-uncertainty intervals. If a source stratum lacks one class, report it explicitly and do not merge it with another stratum. On calibration replicates, refit the unchanged Platt calibrator and retain the score-direction difference and slope; on test replicates, retain raw score-direction difference and AUROC. Report 95% percentile intervals. For JEPA-versus-supervised contrasts, use paired episode resampling with the same sampled episode IDs for both models.
- Keep all windows from an episode together (for H=1 position 0 there is one primary window per episode, but the cluster unit remains the episode).
- Report conditional within-dataset-cell intervals. Do not pool the 25 cells as if they were independent episodes or describe these intervals as confidence intervals over dataset/training-seed populations.
- Report across-cell descriptive distributions separately from episode-bootstrap uncertainty.

## 5. Prespecified direction classification

Classify each model × ((d,m)) cell on the shifted primary test as:

- **Positive direction:** calibration (Delta>0), calibration Platt slope (>0), test (Delta>0), and test AUROC (>0.5).
- **Negative direction:** calibration (Delta<0), calibration Platt slope (<0), test (Delta<0), and test AUROC (<0.5).
- **Calibration/test discordance:** calibration direction and test direction disagree.
- **Weak/inconclusive:** either calibration or test direction is zero/undefined, the relevant class support is missing, or bootstrap intervals do not resolve the direction under the reporting rule.

The sign classification is descriptive. A **supported positive** classification requires calibration delta and Platt-slope 95% intervals wholly above zero, plus test delta interval wholly above zero and test AUROC interval wholly above 0.5. A **supported negative** classification requires all four intervals wholly below their respective thresholds. If calibration and test point directions disagree, classify as discordant even if intervals are wide; if point directions agree but one or more intervals overlap its threshold, classify as weak/inconclusive. Also report continuous effect sizes; do not treat a tiny nonzero point estimate as practically important merely because its sign is nonzero. Reverse-split results are a prespecified robustness diagnostic and never determine the primary classification.

## 6. Validity checks and tests

1. Dataset generation is deterministic for each dataset seed and independent of model-training seed.
2. Model initialization and minibatch ordering are deterministic for each model-training seed and independent of dataset seed.
3. The full 25-cell Cartesian product is executed exactly once per model and split; missing or duplicated cells fail validation.
5. The separate legacy-RNG reproduction pass for the five diagonal cells reproduces the validated prior diagonal position-0 calibration slope and shifted-test raw AUROC, Brier, and score-direction difference with absolute tolerance 1e-12 and zero relative tolerance; discrepancies fail the run and require diagnosis, not silent correction. The exact reference values and source-artifact provenance are retained in `experiments/G8.4/references/g8_4_8_7_7_diagonal_position0_reference.json`.
5. JEPA and supervised models use identical dataset partitions, training data, calibration/test episodes, and paired rollout RNG seeds within each cell.
6. Episode IDs are disjoint across train, validation, calibration, shifted test, and reverse test.
7. Scalers are fit on train only; action-head checkpoint selection uses validation only; action temperature and risk calibration use calibration only.
8. Risk calibration uses only calibration position-0 predictions and labels; no test data are passed to fit routines.
9. Model inference signatures accept only decision-time context; test labels and metadata remain outside inference calls.
10. Test-window position 0 is selected only after E2 predictions are generated, for offline evaluation.
11. The corrected supervised comparator predicts next observable context and re-encodes its own predicted context during recursive rollout; no security-only latent substitution is allowed.
12. Instrumented and production recursive E2 risk predictions remain numerically identical if instrumentation is reused.
13. No predictive score, calibration output, or diagnostic may alter the formal UCON decision. A formal DENY remains authoritative and invariant to model scores.

## 7. Decision rules

To avoid explaining an isolated cell after seeing the matrix, define recurrence before interpreting the results:

- A **dataset-seed-linked recurrence** is present only when at least one dataset-seed row has supported-negative JEPA cells in at least 4 of its 5 model-training-seed columns.
- A **training-seed-linked recurrence** is present only when at least one model-training-seed column has supported-negative JEPA cells in at least 4 of its 5 dataset-seed rows.
- A **JEPA-specific recurrence** additionally requires that the matched supervised cells in the corresponding row/column do not show supported-negative direction in more than 1 of 5 cells, and that the paired JEPA-minus-supervised direction contrasts are consistent with the JEPA failure.
- If no row or column meets these recurrence rules, do not attribute the event to either factor; report cell-level heterogeneity and unresolved interaction/residual variation.

- If negative direction follows the **dataset seed across multiple model-training seeds** for JEPA and supervised, prioritize dataset/task initial-state structure; do not attribute it to JEPA.
- If negative direction follows the **model-training seed across multiple dataset seeds** and is JEPA-specific while supervised remains stable, prioritize a JEPA training-stability investigation. This motivates (but does not itself prove) a later RNG-stream separation and representation/optimization study.
- If both models show comparable model-training-seed sensitivity, treat the phenomenon as a broader training/rollout stability issue before making JEPA-specific claims.
- If the failure occurs only in isolated cells with no coherent row/column pattern, classify it as unresolved cell-level variability; do not tell a causal story from one seed.
- If calibration direction is negative but held-out position-0 raw direction is positive, classify calibration sampling instability; do not flip scores.
- If both calibration and held-out raw direction are negative, retain a genuine position-0 prediction-direction failure for that cell.
- If no negative directions recur, report that the original event was not reproduced in this crossed matrix. Do not conclude it is impossible or repaired.
- No architecture modification is authorized by this protocol. Any future change requires a separate hypothesis, preregistration, and matched-control comparison.

## 8. Limitations

The 5 × 5 matrix is a controlled diagnostic, not a large-scale statistical study. It varies synthetic episode-generation seed and combined model-training stochasticity only. It does not isolate initialization from minibatch order, cover real LLM agents, capture adaptive real-world adversaries, or establish external validity. The benchmark remains limited to five synthetic policy archetypes, three resource families, and the declared scalar policy-mixture shift. No real-agent transfer, intervention utility, production calibration, or production security assurance is claimed.
