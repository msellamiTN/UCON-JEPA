## 1. Experimental setup

- Five seeds: `20261120`–`20261124`.
- Five behavior archetypes × three security families.
- 300 episodes per archetype/family/rho cell.
- Training support rho = 0.20, 0.40, 0.60.
- Primary shifted test rho = 0.85; separate reverse-shift diagnostic rho = 0.05.
- Eight transitions per episode.
- Each seed: 22,500 episodes and 180,000 transitions.
- Across five seeds: 112,500 episodes and 900,000 transitions.
- Feature scaling and model fitting use train only; supervised checkpoint selection uses validation; one temperature per model is fitted on nominal-support calibration only.
- All four models are evaluated on untouched shifted/reverse test partitions.

Comparators: family-conditioned majority, historical-frequency, first-order Markov (using the previous observed action only), and past-only supervised context softmax.

No policy ID, rho, policy configuration, episode ID, partition, future action, future observation or security target is supplied as a model inference feature. The Markov model receives the immediately previous observed action at the current decision point; it uses BOS at episode start.

## 5. Scientific verdict

1. **Action forecasting under parameter shift is learnable in this synthetic setup.** The past-only context model beats the historical-frequency comparator on pooled calibrated NLL and Brier for both rho=0.85 and rho=0.05.
2. **The improvement is not archetype-invariant.** The retrying-adversary primary test is a clear counterexample; the reverse-shift goal-directed/planner strata are also counterexamples.
3. **Historical frequency remains a strong baseline.** It beats the supervised model on some policy strata, so the next JEPA stage must not compare only against a weak majority baseline.
4. **This stage does not evaluate recursive action rollouts, future risk, or intervention utility.** It cannot establish that a JEPA model will forecast security violations.
5. **No real-agent or production generalization claim is established.** The data are generated by five hand-designed archetypes with one scalar mixture parameter.
