# G8.4.8.7.7 — Decision-time matched recursive evaluation

**Status:** protocol and primary-estimand implementation committed; focused and five-seed validation pending.  
**Parent:** G8.4.8.7.5 matched recursive JEPA/supervised comparison and G8.4.8.7.6 calibration-direction diagnosis.  
**Question:** does JEPA improve future-DENY prediction at the actual decision time, when calibration and evaluation use the same one-window-per-episode population?

## 1. Motivation and correction

G8.4.8.7.5 fitted horizon-specific Platt calibrators on exactly one start-step-0 window per nominal-support calibration episode, but its headline metrics pooled all overlapping sliding test windows. This was an estimand mismatch: the distribution of later-start windows differs from the decision-time population, and each episode contributed multiple correlated windows.

G8.4.8.7.6 showed that the discrepancy can be material. For seed 20261122 at H=1 under rho=.85, the unconstrained Platt slope was -0.175. On start-step-0 test windows, raw AUROC was 0.4511 and calibrated AUROC 0.5489; on all sliding windows, calibrated AUROC was 0.2606. The action-head observed-context metrics were not anomalous relative to other seeds. The evidence does not establish that the action head is the source of failure.

This stage does not alter the models, generator, splits, calibration algorithm, or test data. It corrects the primary evaluation population.

## 2. Frozen models and data

Reuse the exact G8.4.8.7.5 models and generator:
- JEPA E2 with EMA target encoder and latent predictive objective.
- Directly supervised state-dynamics E2, predicting next observable context and security targets, then re-encoding predicted context for recursive inference.
- Five seeds: 20261120–20261124.
- Five behavior archetypes × three security families.
- 300 episodes per archetype/family/rho cell.
- Train rho {0.20, 0.40, 0.60}; shifted test rho=0.85; reverse diagnostic rho=0.05.
- Horizons H={1,2,4,8}; 32 Monte Carlo action rollouts.
- Same episode-disjoint train, validation, calibration, shifted-test and reverse-test partitions.
- Same model-fitting and action-head budgets as G8.4.8.7.5.

No new model selection or hyperparameter search is permitted.

## 3. Primary estimand: decision-time prediction

For each episode and horizon, select exactly one forecast window whose start_step is 0. Assert that:
1. every episode has one and only one such window;
2. no episode contributes more than one primary row;
3. the calibration and test selection rules are identical;
4. target labels are the any-DENY-within-next-H outcome for that window.

Fit each model's horizon-specific ridge-Platt calibrator on one start-step-0 window per nominal-support calibration episode. Evaluate calibrated probabilities on one start-step-0 window per shifted/reverse test episode.

Primary endpoint: Brier score at rho=.85. Primary contrast: JEPA E2 minus supervised E2 Brier; negative favors JEPA.

Report AUROC, AUPRC, 10-bin ECE, target prevalence, model calibration, and paired episode bootstrap intervals. Bootstrap resamples complete episodes (one row per episode), 2,000 replicates per seed/split/horizon. Report each seed separately and across-seed mean ± sample SD; do not interpret the five synthetic seeds as a population-level hierarchical confidence interval.

Use the training partition's start-step-0 windows to estimate the horizon-matched prevalence baseline.

## 4. Secondary estimand: sliding-window diagnostics

Retain all overlapping windows as a secondary descriptive analysis for continuity with G8.4.8.7.5. Clearly label these as correlated, multiple windows per episode. They are not the primary calibrated decision-time estimand and must not determine the main scientific verdict.

Report secondary all-window metrics separately. Do not pool primary and secondary rows.

## 5. Subgroups and uncertainty

For the primary start-step-0 population, report every behavior-archetype × security-family cell, per seed, for both rho values and all horizons. Mark AUROC undefined for single-class cells; do not impute it.

Report Monte Carlo risk dispersion for the primary windows. Keep the observed-context action-head diagnostic separate from recursive predicted-latent action behavior.

## 6. Information and authorization boundary

At inference, both models receive only the initial context and generate their own future actions autoregressively using their past-only action heads. Future actions, future observations, security targets, policy IDs, rho, episode IDs, step indices, and partition labels remain unavailable to the inference functions.

Formal UCON remains the sole authorization authority. Predictive outputs cannot authorize an operation or override DENY.

## 7. Acceptance gates

1. Complete G8.4 regression suite passes.
2. Focused tests prove the one-start-window-per-episode selection rule and reject missing/duplicate episode starts.
3. Small benchmark smoke test verifies primary window count equals episode count for every horizon/split.
4. Five-seed full benchmark completes for both rho conditions and all horizons.
5. Calibration is fitted only on calibration start-step-0 rows; test data is never used to fit or choose calibration.
6. Paired whole-episode bootstrap and all 15 archetype/family subgroups are retained.
7. Artifact includes frozen datasets/manifests/checksums, configs, raw/calibrated metrics, subgroup tables and seed-level intervals.
8. No JEPA superiority claim unless decision-time paired evidence, seed stability and subgroup behavior support it.

## 8. Interpretation boundary

This experiment can resolve whether the earlier JEPA-versus-supervised comparison was distorted by calibration/evaluation population mismatch. It remains a synthetic controlled-shift evaluation and cannot establish real-agent transfer, intervention utility, or production security assurance.
