# G8.4.8.7.9 — Initialization vs. Minibatch-Order Seed Decomposition Protocol

**Status:** preregistered protocol proposal; no implementation or execution  
**Depends on:** G8.4.8.7.8 results in PR #52  
**Motivation:** isolate the two stochastic controls currently combined in `JEPAConfig.seed` after the G8.4.8.7.8 crossed-seed audit found a JEPA-specific negative-direction recurrence associated with combined training seed 20261122.

## 1. Research question

Does the G8.4.8.7.8 negative initial-position direction defect follow:

1. parameter initialization;
2. minibatch permutation order;
3. an interaction between initialization and minibatch order; or
4. neither factor reproducibly?

The model-training seed in G8.4.8.7.8 controls both initialization and minibatch permutation. That experiment does not identify which component is responsible. This protocol separates them without changing the learning objective, model capacity, optimizer, data generator, inference information boundary, calibration method, or authorization behavior.

## 2. Hypotheses

- **H-I (initialization-linked):** the negative JEPA direction follows an initialization-seed level across dataset seeds and minibatch-order seeds.
- **H-M (minibatch-order-linked):** the negative JEPA direction follows a minibatch-order-seed level across dataset seeds and initialization seeds.
- **H-IM (interaction):** neither marginal factor alone explains the recurrence; the defect is concentrated in particular initialization × minibatch-order combinations.
- **H-N (no reproducible factor):** the G8.4.8.7.8 pattern does not recur under independent factor control.

The matched supervised recursive E2 model is retained in every cell. The diagnostic is JEPA-specific only if the matched control does not exhibit the corresponding direction defect.

## 3. Factorial design

A fully crossed 5 × 5 × 5 design:

| Factor | Levels | Meaning |
|---|---|---|
| Dataset-generation seed | 20261120–20261124 | Five independently generated datasets |
| Initialization seed | 20261120–20261124 | Initial parameter draws only |
| Minibatch-order seed | 20261120–20261124 | Per-epoch training-row permutations only |

Total: 125 cells. Each dataset is generated once and reused for all 25 initialization × minibatch-order combinations. Each cell fits both JEPA E2 and matched supervised recursive E2 on the same training data and uses the same validation/calibration/test partitions.

The historical problematic combined value 20261122 is deliberately included as a level of **each** factor, but the new independent RNG streams do not reproduce the legacy combined stream. Legacy reproduction is a separate compatibility control (Section 8).

### RNG separation requirement

- Initialization must use a generator seeded only by `initialization_seed`.
- Every epoch's minibatch permutation must use a separate generator seeded only by `minibatch_order_seed`.
- The two generators must not share state, consume each other's draws, or depend on dataset seed.
- The same initialization and minibatch-order seeds must initialize/permutate the corresponding JEPA and supervised models under the existing model-specific parameter shapes. Parameter arrays are not expected to be identical across architectures where shapes or initialization draw counts differ.
- Action-head fitting, scaling, calibration, MC rollouts, and bootstrap resampling must not consume either training RNG stream.
- Add unit tests proving: changing minibatch-order seed leaves initial parameter arrays unchanged; changing initialization seed leaves the first and subsequent minibatch permutations unchanged; same factor seeds reproduce exactly; and different factor seeds alter only their designated stochastic component.

The existing backward-compatible `seed` behavior must remain unchanged for all previous experiments. New explicit `initialization_seed` and `minibatch_order_seed` configuration fields must be optional and must not change results when omitted.

## 4. Fixed training and evaluation protocol

Retain the G8.4.8.7.8 settings exactly:

- JEPA E2 and corrected matched supervised recursive E2; no architecture, loss, optimizer, capacity, epoch, batch-size, or early-stopping changes.
- 300 episodes per archetype × policy cell, same synthetic generator and five dataset seeds.
- 180 epochs; H=1; 32 MC rollouts.
- Calibration and primary shifted-test evaluation use trajectory start position 0 only.
- Primary shifted test: policy parameter ρ=0.85.
- Reverse ρ=0.05 remains diagnostic only.
- Episode-disjoint train, validation, calibration, shifted-test, and reverse-test partitions must be asserted for every generated dataset.
- 2,000 paired whole-episode bootstrap replicates per cell, stratified by policy archetype × resource family × binary label, preserving observed stratum counts and reporting absent strata explicitly.
- Calibrator is fit on calibration position-0 observations only; no test-driven sign correction, score flipping, or model selection.
- MC rollout randomness is fixed globally across all 125 cells and both models, independent of dataset, initialization, and minibatch-order factors. Bootstrap randomness uses a separate deterministic stream, independent of all three factors.
- Retain episode-level predictions, labels, policy/family metadata, seed metadata, model metrics, calibrators, confidence intervals, subgroup availability, and checksums.

The full benchmark is expected to be materially larger than G8.4.8.7.8. CI timeout and resource needs must be evaluated before implementation; do not reduce the preregistered cell count, epochs, MC samples, or bootstrap replicates after seeing results. If resource constraints make the full design infeasible, stop and amend the protocol before running the confirmatory benchmark.

## 5. Primary endpoints and cell classification

For each dataset × initialization × minibatch cell and each model, retain:

1. calibration position-0 positive-minus-negative raw-score mean difference;
2. unconstrained Platt calibration slope;
3. shifted-test position-0 raw-score positive-minus-negative mean difference;
4. shifted-test position-0 raw AUROC;
5. raw and calibrated Brier scores.

A cell is **supported-negative** only if all four preregistered 95% episode-bootstrap intervals are strictly negative / below chance as appropriate: calibration score-direction delta, calibration slope, shifted-test score-direction delta, and shifted-test AUROC (upper endpoint below 0.5). It is **supported-positive** only if all four intervals are strictly positive / above chance as appropriate. If point directions conflict, classify discordant; if intervals overlap the thresholds, classify weak/inconclusive.

The same classification function and bootstrap method must be applied to JEPA and supervised controls. Brier score is reported but is not part of direction classification.

## 6. Factor-specific recurrence rules

A marginal factor level contains 25 cells: five dataset seeds × five levels of the other training factor.

A factor level is **supported-negative recurrent** only when at least 20/25 JEPA cells are supported-negative. A JEPA-specific recurrence additionally requires:

- no more than 5/25 matched-supervised cells supported-negative;
- at least 20/25 paired JEPA-minus-supervised raw-AUROC bootstrap intervals wholly below zero; and
- at least 20/25 paired JEPA-minus-supervised calibration-slope bootstrap intervals wholly below zero.

Apply these criteria separately to each initialization-seed level and each minibatch-order-seed level. These thresholds are preregistered operational criteria, not claims of a population-level 80% probability.

Interpretation:
- H-I supported: recurrence in one initialization-seed slice, not mirrored in supervised, with the paired criteria met.
- H-M supported: recurrence in one minibatch-order-seed slice, not mirrored in supervised, with the paired criteria met.
- H-IM candidate: concentrated negative cells in initialization × minibatch combinations without a qualifying marginal slice. Report the full 5 × 5 interaction heatmap; do not claim a separately estimated interaction variance component.
- H-N candidate: no factor slice meets recurrence and no stable interaction pattern is evident.

If both marginal factors meet criteria, report both; do not force a single-cause conclusion. Report all 125 cell classifications, not only recurrent slices.

## 7. Statistical summaries and limitations

- Report per-factor-level means and sample SDs across the 25 cells, with the raw cell values.
- Report balanced additive decompositions for dataset, initialization, and minibatch-order factors, retaining all cell residuals.
- With one observation per three-factor cell, the three-way interaction is confounded with residual; do not report it as separately identified.
- Episode bootstrap intervals quantify within-cell episode sampling uncertainty conditional on observed class counts. They do not turn five seed levels into a large sample of independent training runs.
- The 20/25 recurrence rule is descriptive and preregistered. Do not interpret it as a conventional p-value or causal proof.
- Report all one-class or unavailable subgroup metrics explicitly.
- No real-agent generalization, deployment readiness, intervention utility, or production security assurance claim.

## 8. Legacy compatibility control

Run the original G8.4.8.7.8 combined-seed path unchanged for the five diagonal seeds and compare retained summary metrics against the archived G8.4.8.7.7 reference and G8.4.8.7.8 diagonal evidence. This control must reproduce the historical path at the existing strict tolerance. It is separate from the new independent-stream factorial matrix; do not pretend a cell in the new matrix is a legacy reproduction.

The compatibility check must include the historical seed 20261122 negative JEPA result and the matched supervised result. If the old path no longer reproduces exactly, stop and diagnose before running the new factorial matrix.

- Legacy compatibility control passes.
