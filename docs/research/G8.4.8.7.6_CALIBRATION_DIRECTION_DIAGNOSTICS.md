# G8.4.8.7.6 — JEPA calibration-direction and seed-stability diagnosis

**Status:** implementation committed; focused tests and five-seed benchmark pending.  
**Parent:** G8.4.8.7.5 matched recursive control.  
**Question:** does the seed-20261122 H=1 ranking inversion originate in the raw JEPA risk score, calibration fit, action head, or recursive latent/action rollout?

## 1. Frozen data and inference boundary

Reuse the G8.4.8.7.1 generator and identical split rules:
- five seeds 20261120–20261124;
- five archetypes × three security families;
- train rho {0.20, 0.40, 0.60};
- untouched shifted test rho=0.85 and reverse diagnostic rho=0.05;
- horizons 1, 2, 4, 8;
- 32 Monte Carlo action trajectories.

No model or calibration parameter is selected using shifted or reverse test outcomes. E2 inference receives only the initial context, the model's current predicted latent, and known family features. Future actions, observations, security labels, policy identity, rho, episode IDs, step indices and partition labels are not inference inputs.

## 2. Calibration audit

For each seed/horizon:
1. Generate raw JEPA E2 risk scores on nominal-support calibration episodes.
2. Fit the existing ridge-Platt calibrator using exactly one predeclared start-step-0 window per calibration episode.
3. Fit a nonnegative-slope ridge-Platt diagnostic on the same calibration-only windows. This is a sensitivity analysis, not a replacement selected from test performance.
4. Report calibration class balance, raw score distribution, positive/negative score means, unconstrained slope/intercept, constrained slope/intercept, and calibration AUROC/AUPRC/Brier.
5. On untouched shifted and reverse tests, report raw, unconstrained-calibrated and nonnegative-calibrated AUROC/AUPRC/Brier/ECE. Report all windows and start-step-0 windows separately.

A negative unconstrained slope is not automatically a bug: it may indicate the model's calibration scores are inversely associated with outcomes on the calibration distribution. The diagnostic must determine whether the held-out reversal already exists in raw scores or is introduced by the calibration map. Never flip score direction based on test labels.

## 3. Recursive rollout diagnostics

Instrument the exact E2 sampling/update loop and assert its final risk mean is numerically identical to the production rollout under the same seed. Per rollout step, retain:
- action entropy and maximum action probability;
- mean action probabilities and sampled action frequencies;
- predicted-latent norm and dispersion;
- decoded per-step DENY probability and dispersion.

Also report the observed-context action-head test metrics separately. They diagnose the action head on real observed contexts but must not be presented as recursive predicted-latent action performance.

## 4. Acceptance and interpretation

- Complete G8.4 regressions and focused diagnostic tests pass.
- Instrumented and production rollout outputs match to numerical tolerance.
- All calibrators are finite; nonnegative diagnostic slopes are nonnegative.
- Same fixed seeds, splits, model fitting budget and inference boundary.
- Report every seed; seed 20261122 is not removed or down-weighted.
- If raw calibration and test score directions differ, report this as a distribution-shift failure. If only calibrated ranking reverses, identify calibration as the cause. If action-head or latent diagnostics diverge, report that source separately.
- No test-driven calibration selection and no claim that monotone calibration repairs the predictor unless confirmed on a new untouched test population.

## 5. Safety boundary

This experiment is a synthetic model-diagnostics study. Risk predictions remain advisory. Formal UCON is the only authorization authority; a formal DENY cannot be overridden.
