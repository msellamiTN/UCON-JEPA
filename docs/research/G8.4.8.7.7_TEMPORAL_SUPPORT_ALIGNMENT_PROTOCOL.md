# G8.4.8.7.7 — Temporal-Support Alignment Audit

**State:** preregistered; implementation, five-seed execution, artifact verification, and results review completed  
**Depends on:** G8.4.8.7.5 matched recursive control and G8.4.8.7.6 calibration diagnostics  
**Branch:** `research/g8.4.8.7.7-temporal-support-alignment`

## 1. Motivation and falsifiable question

G8.4.8.7.6 found that the H=1 risk calibrator is fitted using only windows whose start position is 0, while the all-window H=1 test metric pools windows starting at positions 0 through 7. For seed 20261122, raw H=1 AUROC is below 0.5 on start-position-0 test windows but substantially above 0.5 when later start positions are pooled. A calibrator fitted only on position 0 reverses the ranking on the pooled test distribution.

This experiment asks:

> Does the apparent H=1 calibration-direction failure persist when calibration and evaluation use the same trajectory-position support, or is the large pooled-test reversal primarily caused by applying a position-0 calibrator to a different temporal mixture?

This is a diagnostic of calibration support and score direction. It is not a proposal to modify the predictor or authorization system.

## 2. Fixed experimental conditions

- Seeds: 20261120, 20261121, 20261122, 20261123, 20261124.
- Dataset: existing G8.4.8.7.1 parameterized synthetic dataset; 5 behavior archetypes × 3 resource families; 8 transitions per episode.
- Training mixture: \(\rho \in \{0.20,0.40,0.60\}\).
- Untouched test mixtures: shifted \(\rho=0.85\), reverse diagnostic \(\rho=0.05\).
- Horizons: \(H \in \{1,2,4,8\}\).
- Monte Carlo rollouts: 32, same E2 inference implementation and seed derivation as G8.4.8.7.6.
- Models: existing JEPA E2 and the corrected G8.4.8.7.5 directly supervised recursive state-dynamics control.
- Same episode partitions, feature scalers fitted on training only, optimizer/training budgets, action-head fitting, and evaluation windows as the parent benchmarks.
- No architecture, loss, optimizer, training data, or action policy changes in this stage.

For horizon \(H\), valid window start positions are \(p \in \{0,\ldots,8-H\}\). Thus H=1 has eight temporal positions; H=8 has only position 0. The number of windows and unique episodes must be reported separately.

## 3. Prespecified calibration-support conditions

Use the existing ridge-Platt calibration objective, including its fixed score-logit standardization and slope penalty of 1.0. Do not add a sign constraint or select a calibrator based on test performance.

For each seed, model, and horizon, fit and evaluate these three fixed conditions:

### C0 — Legacy position-0 calibration

Fit one calibrator on nominal calibration windows with `start_step == 0`; apply it to every test window. This reproduces the G8.4.8.7.6 support mismatch and is retained only as a diagnostic comparator.

### CP — Position-matched calibration

For every valid start position \(p\), fit a separate calibrator using only nominal calibration windows with `start_step == p`; apply it only to test windows with the same start position. Aggregate the resulting per-position predictions only after each position has been calibrated on its matching support. Report every position separately as well as the pooled aggregate.

### CA — All-position pooled calibration

Fit one calibrator using all valid start positions in the nominal calibration partition; apply it to all test windows across exactly the same set of positions. This tests whether a single pooled calibrator is adequate when its calibration support matches the pooled evaluation support.

All calibration fits use calibration partition only. No test statistic may choose between C0, CP, or CA. All three are reported regardless of outcome.

## 4. Required metrics and decomposition

For each model × seed × horizon × test split × support condition, retain:

- calibration and test window counts, unique episode counts, position counts, and class prevalence;
- raw score mean, standard deviation, quantiles, positive/negative means, and positive-minus-negative mean;
- raw AUROC, AUPRC, Brier, and ECE;
- calibrated AUROC, AUPRC, Brier, and ECE;
- fitted Platt intercept, slope, score-logit center and scale, and convergence diagnostics;
- confusion-derived quantities only at a prespecified threshold, clearly secondary to ranking/proper scoring metrics.

For each start position, report the same raw score summaries and raw metrics, including the sign of positive-minus-negative mean. For CP, report per-position calibration coefficients and test metrics. For CA and C0, report per-position test metrics after applying the common calibrator so that cross-position distortion remains visible.

Stratify by all 15 behavior-archetype × resource-family cells. A cell with insufficient class support must be explicitly marked unavailable; never silently omit it or pool it into another cell.

## 5. Primary and secondary analyses

**Primary analysis:** for each seed/model/horizon/test split, compare the pooled all-window Brier score under C0 versus CA on the identical all-window test set. Report the paired difference (CA minus C0; negative favours CA), with a whole-episode paired bootstrap interval. This contrast directly tests whether matching the calibrator's support to the pooled evaluation support changes probabilistic error.

**Key diagnostic:** compare raw score direction between calibration and test within each identical start position. Report direction agreement per seed and position; do not treat a positive/negative mean difference alone as a significance test.

**Secondary analyses:**
- pooled Brier/AUROC/AUPRC/ECE under CP and CA;
- per-position metrics and calibration slopes;
- position-specific and archetype/family-specific results;
- paired JEPA-minus-supervised differences under each identical support condition;
- seed-level means and sample standard deviations, alongside each seed's full results.

Use 2,000 paired whole-episode bootstrap replicates. Resample episode IDs, keeping all windows from a sampled episode together. Where a comparison is stratified, resample episodes within the fixed archetype × family strata and preserve the observed stratum allocation. Overlapping windows are never treated as independent bootstrap units. Report conditional within-seed intervals as such; do not describe them as hierarchical confidence intervals over the five synthetic seeds.

## 6. Information-boundary and implementation requirements

- E2 inference receives only the initial context and learned parameters. Future actions, future observations, future security labels, policy identity, episode identifiers, start positions, and calibration/test split labels must not enter model inference.
- Start positions, episode IDs, archetype and family are permitted only for offline evaluation grouping, bootstrap clustering, and calibration partitioning after model scores have been produced.
- Fit feature scalers on train only. Fit action-head temperature on calibration only, as in the parent protocol. Keep risk calibration separate from the action-policy head.
- The instrumented and production recursive rollouts must remain numerically identical.
- The supervised control must use its own predicted-observation context path and re-encoder; do not substitute a security-only latent for a context latent.
- Formal UCON remains the only authorization authority. Neither raw nor calibrated risk may permit, deny, or override an operation.

## 7. Required tests

1. Window construction yields exactly the valid start positions \(0,\ldots,8-H\) for every complete eight-step episode.
2. C0 selects only position 0 in calibration and deliberately applies to all test positions.
3. CP fits exactly one calibrator per valid position and never crosses position boundaries.
4. CA fits on all and only valid calibration windows and evaluates on the matching all-position test support.
5. Calibration and test episode IDs are disjoint; no test labels or test score distributions enter fitting.
6. Every metric row has explicit model, seed, horizon, split, start position/support condition, window count, and unique episode count.
7. Bootstrap resampling clusters all windows from an episode; tests detect a deliberately window-level bootstrap mutant.
8. Missing positive or negative class support fails loudly or is marked unavailable under the predeclared rule; it is never silently converted to AUROC 0.5.
9. E2 inference signatures and tests reject future action, future observation, security label, policy, and start-position inputs.
10. Instrumented rollout matches production E2 risk means to numerical tolerance.
11. UCON DENY decisions are invariant to predictor scores, calibration coefficients, and intervention diagnostics.

## 8. Decision rules (no test-driven model selection)

- If C0 fails on pooled test but CP and CA are stable, classify the main observed inversion as a calibration-support mismatch. Do not claim the JEPA representation is repaired or superior.
- If raw direction is unstable even when calibration and evaluation are matched position-by-position, retain a model/initial-state direction failure. The next stage may then investigate JEPA initialization, representation geometry, and training-seed sensitivity.
- If CP is stable but CA is not, report position-dependent calibration heterogeneity; do not deploy a single pooled calibrator without further evidence.
- If both JEPA and the matched supervised control show the same pattern, attribute the failure first to temporal-support/task construction rather than JEPA-specific representation learning.
- If the failure is JEPA-specific under matched supports while the supervised control is stable, this motivates a separate representation/optimization investigation. It does not by itself prove a JEPA mechanism.
- No condition is selected for deployment based on the shifted or reverse test outcomes.

## 9. Limitations

The benchmark is synthetic, contains five hand-designed behavior archetypes and three resource families, and varies one scalar within-archetype mixture parameter. It does not model real LLM agents, tool APIs, adaptive adversaries beyond the declared policies, or production policy drift. Five seeds are insufficient for broad population-level claims. Calibration on synthetic episodes does not establish operational calibration. No real-agent generalization, intervention utility, or production security assurance is claimed.
