## 2. Primary finding: the seed-20261122 inversion is a temporal-support mismatch

Calibration uses **one start-step-0 window per nominal-support calibration episode**. The reported all-window test metric pools windows from multiple trajectory positions. Those are not the same temporal distribution.

For seed 20261122 at horizon 1:

| Quantity | Shifted \(\rho=.85\) | Reverse \(\rho=.05\) |
|---|---:|---:|
| Calibration raw positive-minus-negative score mean | -0.00935 | -0.00935 |
| Unconstrained calibration Platt slope | -0.1750 | -0.1750 |
| Nonnegative-slope diagnostic | 0.0000 | 0.0000 |
| Test step-0 raw AUROC | 0.4511 | 0.4430 |
| Test all-window raw AUROC | 0.7394 | 0.7336 |
| Test all-window unconstrained-Platt AUROC | 0.2606 | 0.2664 |
| Test all-window nonnegative-Platt AUROC | 0.5000 | 0.5000 |

The negative calibration slope is **not an isolated numerical optimizer defect**: the raw score's calibration positive-minus-negative mean is already negative, and the untouched step-0 test subset has raw AUROC below 0.5. However, the same seed's all-window raw test AUROC is about 0.74. Applying a calibrator fitted only to start-step-0 windows therefore reverses the ranking on the pooled all-window evaluation.

The constrained nonnegative fit lands at slope zero. Its AUROC of 0.5 is a constant-score degeneracy, not a successful repair. It removes the reversal by discarding ranking information.

This is stronger and more precise than describing the issue simply as “Platt calibration flips a good raw model”: **the calibration support and the pooled evaluation support have materially different temporal score-label relationships for this seed.** The raw predictor itself has a step-0 direction problem in this seed, while later-window observations change the pooled relationship.

## 4. Action-head and recursive-path diagnostics

The observed-context action head for seed 20261122 has NLL 1.0605, top-1 accuracy 0.4221, top-2 accuracy 0.7544, multiclass Brier 0.6407, and top-label ECE 0.0180 over 36,000 examples. This is a separate observed-context diagnostic; it is not a direct measure of the recursive predicted-latent action sequence.

The instrumented recursive rollout records action entropy/probabilities, sampled action frequencies, latent norms, and decoded DENY probabilities. The implementation test asserts numerical equivalence with production E2 inference. These traces are diagnostic only: they do not establish that the learned action sequence is behaviorally faithful to real agents, nor do they establish intervention utility.

## 5. Scientific verdict

1. **The calibration-direction failure is real and reproducible in seed 20261122.** The raw score relation is already negative on the calibration/start-step-0 support.
2. **The pooled all-window ranking reversal is caused by applying a start-step-0 calibrator to a temporally different evaluation mixture.** The same seed has below-chance step-0 raw AUROC but substantially above-chance all-window raw AUROC.
3. **A nonnegative-slope constraint is not a repair.** In this case it produces a zero-slope constant predictor (AUROC 0.5).
4. **No calibration method is selected or changed based on test outcomes.** All seeds remain included.
5. **No JEPA superiority claim follows.** G8.4.8.7.5 still shows the matched supervised recursive control outperforming JEPA at H=1/H=2 overall, with H=4/H=8 near ties and seed/subgroup heterogeneity.
6. The evidence is limited to this synthetic five-archetype, scalar-mixture controlled-shift setting. No real-agent transfer, production calibration, or security assurance is established.

## 6. Next experiment: temporal-support alignment audit (G8.4.8.7.7)

Do not add another model architecture yet. The next experiment should isolate whether the observed instability is caused by calibration/evaluation temporal-support mismatch or by a genuine initial-state representation defect.

Pre-register and execute, on the same five seeds and with no test-driven selection:

- Calibration and evaluation reported separately for each trajectory position (step 0 through step 7), with per-position score distributions, positive/negative means, AUROC/AUPRC, Brier, and ECE.
- A strict matched-support comparison: fit calibration on step-0 calibration windows and evaluate only step-0 test windows; separately fit on a prespecified pooled set of calibration positions and evaluate on the matching pooled test positions. Keep the calibration-position sets fixed before test evaluation.
- Report raw scores and calibrated scores side by side. Include calibration slope/intercept, sample counts, class prevalence, and uncertainty intervals.
- Add per-position subgroup breakdowns by behavior archetype and resource family; preserve episode-level resampling to avoid treating overlapping windows as independent.
- Keep the current production E2 inference path unchanged. Calibration is a downstream reporting transform and must never feed back into action prediction or formal UCON authorization.
- Compare against the same supervised recursive control using identical support definitions.
- Add tests that fail if calibration and evaluation temporal supports are silently mixed, if any test statistic selects a calibration method, or if a predictor/calibrator can alter the formal UCON decision.

**Decision gate:** only if matched-support calibration still exhibits seed-unstable score direction should a subsequent experiment investigate initial-context representation/JEPA optimization. If matched-support results are stable but pooled-support results fail, record the issue as a support-mismatch/calibration protocol defect rather than claiming a JEPA representation collapse.
