# G8.4.8.8 — Randomized Predictive-Intervention Utility

**State:** preregistration; implementation and execution not started  
**Depends on:** G8.4.7 fixed-length trajectories; G8.4.8.7 policy-shift benchmarks; G8.4.8.7.7 temporal-support audit  
**Parent branch:** `research/g8.4.8.7.7-temporal-support-alignment`  
**Working branch:** `research/g8.4.8.8-randomized-intervention-utility`

## 1. Research question and scope

Does a predictive, model-triggered advisory warning reduce harmful/denied agent actions when the agent can adapt to the warning, beyond reactive formal UCON enforcement alone and beyond a warning with no predictive information?

This is an intervention-utility experiment, not another offline prediction leaderboard. A predictor is useful only if its warning changes subsequent agent behaviour in a beneficial way without weakening authorization, increasing harmful task completion, or imposing unacceptable alert burden.

The benchmark remains synthetic. It cannot establish utility for real LLM agents, production security, or deployment populations.

**Non-negotiable authority boundary:** every proposed action, including an action selected after a warning, is passed through the same formal UCON oracle and online enforcement gate. JEPA, supervised prediction, calibration, warning thresholds, and intervention code cannot authorize, deny, or override an operation. A warning is advisory feedback to the agent only.

## 2. Falsifiable hypotheses

- **H1 (primary):** under the shifted test mixture `rho=0.85` and the prespecified partially responsive agent condition `q=0.5`, JEPA-triggered warnings reduce the episode-level denied-action rate relative to reactive UCON-only operation.
- **H2:** JEPA-triggered warnings outperform a random-warning control with the same nominal calibration alert budget. This tests whether predictive targeting adds value beyond generic interruption.
- **H3:** the JEPA arm is non-inferior to the supervised-risk-warning arm on denied-action rate, using a predeclared absolute margin of 0.02. This is a comparative model question, not an assumption that JEPA must win.
- **H4 (mechanism/negative control):** when the agent response propensity is `q=0`, predictive warnings do not change the agent's proposed actions or denied-action rate relative to the no-warning arm, apart from Monte Carlo/randomization error.
- **H5 (effect modification):** intervention effects differ across response propensities `q in {0, 0.5, 1}` and the five declared behavior archetypes. These interactions are secondary and must not be used to select a favourable subgroup after seeing test outcomes.

The primary hypothesis is not considered supported merely because a predictor has high AUROC or because warning precision is high.

## 3. Experimental units, environment, and data

### 3.1 Unit and episode semantics

The independent experimental unit is one complete eight-transition episode. Assignment occurs once per episode and remains fixed for all eight decisions. Windows, actions, transitions, and repeated warnings within an episode are not independent statistical units.

Use the existing G8.4.8.7.1 synthetic environment and its five behavior archetypes:

1. `goal_directed`
2. `uniform`
3. `retrying_adversary`
4. `prerequisite_blind_planner`
5. `denial_adaptive_explorer`

Retain the three resource families: IAM, data access, and separation of duties (SoD). Retain the controlled policy-mixture parameter `rho`, with nominal training/calibration support `{0.20, 0.40, 0.60}`, shifted test support `0.85`, and reverse diagnostic support `0.05`.

Each episode has exactly eight decisions. DENY leaves protected workflow state unchanged; attempt history and explicit denial feedback may be observed by the agent. The formal oracle and online gate must agree at every transition.

### 3.2 Warning-response model

G8.4.7/G8.4.8.7 do not model an agent receiving a predictive warning. This stage must add an explicit, versioned response mechanism rather than pretending the existing trajectories already contain intervention effects.

Assign each episode a response propensity `q in {0, 0.5, 1}`, balanced within behavior-archetype × resource-family × `rho` × seed strata. When a warning is issued:

- Draw a response coin from an episode/step-specific exogenous random stream.
- With probability `q`, the agent revises its just-proposed action by selecting uniformly from the other actions in that resource family's declared action vocabulary.
- With probability `1-q`, it retains its original proposal.
- The revised proposal is not selected using UCON labels, denial reasons, future states, or an oracle query. It is not guaranteed to be safer.
- The final proposal is then evaluated by the unchanged formal UCON gate. Any DENY feedback may affect later base-policy proposals according to the declared behavior archetype.

This is intentionally a simple, transparent response model. It isolates whether risk-targeted advisory interruption can help when an agent is partially responsive. It is not a behavioural model of real LLM agents. Report `q=0` as a mechanism negative control, `q=0.5` as the primary response condition, and `q=1` as a high-compliance sensitivity condition.

Use independent, keyed pseudo-random streams for (i) the base behavior policy, (ii) warning-response coin flips, (iii) alternative-action selection, (iv) random-arm warning draws, and (v) Monte Carlo model rollouts. Derive each stream from immutable experiment seed, episode identifier, step, and stream label; never share a mutable RNG stream across these mechanisms. This prevents a warning branch from changing later base-policy randomness merely by consuming an extra draw, and makes the `q=0` negative control exactly testable under matched episode seeds. Publish the derivation rule and stream identifiers in the manifest.

No response parameter may be fitted on test outcomes.

## 4. Arms and randomized assignment

For each horizon cohort, assign episodes to four arms:

- **A0 — Reactive UCON only:** no predictive or random warning; all proposals are still formally enforced.
- **A1 — JEPA advisory:** warn when the JEPA E2 risk score crosses its frozen position-specific threshold.
- **A2 — Supervised advisory:** same warning semantics, using the independently trained supervised recursive risk model.
- **A3 — Random advisory:** issue warnings from an outcome-independent random process with the same nominal calibration alert budget as the predictive arms.

Randomize at the episode level, stratified by seed, behavior archetype, resource family, `rho`, and response propensity. Use reproducible assignment seeds and publish the assignment manifest before test outcome analysis. Balance arm counts within each stratum. Do not reassign an episode after observing any action, warning, or outcome.

Primary inference uses the shifted test mixture `rho=0.85`. The reverse mixture `rho=0.05` is a prespecified robustness analysis. The primary cohort is `q=0.5`; `q=0` and `q=1` are prespecified secondary cohorts.

Use independent test episodes per arm. Do not reuse a single episode's observed trajectory as if it were four randomized units. If common-random-number variance reduction is implemented, it must preserve episode-level randomization and be described separately from the confirmatory randomized estimate.

## 5. Predictors, horizons, and warning threshold

### 5.1 Predictors

Train JEPA E2 and the directly supervised recursive state-dynamics comparator on the same no-warning training partition, with fixed training budgets and seed schedule. Both must predict from the current observable context and their own past-only action-policy head. Neither receives future actions, future observations, future security labels, policy identity, `rho`, episode identifiers, response propensity, arm assignment, warning state, or start position as model inputs.

At each eligible decision point, evaluate the predictor on the current context and let it autoregressively sample its own future action sequence. The risk target is at least one formal UCON DENY within the next `H` transitions. The model's score is used only to decide whether to issue an advisory warning.

### 5.2 Horizons

- **Primary horizon:** `H=1`, evaluated at every decision point.
- **Secondary horizons:** `H=2` and `H=4`, evaluated only where a complete future window remains.
- **Exploratory horizon:** `H=8`, one episode-start decision only.

Each horizon is a separately randomized cohort so that treatment definitions and exposure counts remain explicit. Do not pool windows across horizons as independent observations.

### 5.3 Fixed alert budget and temporal support

Do not use Platt calibration to trigger interventions in this stage. G8.4.8.7.7 demonstrated seed-sensitive calibration-direction instability, and a warning policy does not require interpreting the score as a probability.

For each model × horizon × decision position, use only calibration-partition scores from that same position. Freeze the threshold at the empirical 90th percentile (nominal 10% alert budget), with deterministic, outcome-independent tie-breaking. A position with insufficient calibration support is an implementation failure, not a reason to borrow test data or silently pool positions.

The random-warning arm uses a frozen 0.10 warning probability at each eligible decision point, independent of model scores and all outcomes. Report realized alert rates in every arm and subgroup. Do not retune thresholds to equalize test alert rates.

Thresholds, tie-breaking, and all random seeds must be stored in the experiment manifest before test labels are read.

## 6. Outcomes and estimands

### 6.1 Primary outcome

For episode (i), define denied-action burden:

[
Y_i = \frac{1}{8}\sum_{t=1}^{8}\mathbf{1}\{\text{formal UCON decision}_{it}=\mathrm{DENY}\}.
]

The primary estimand is the intention-to-treat (ITT) mean difference:

[
\Delta_{J,U} =
\mathbb{E}[Y_i\mid A_i=A1,\rho=0.85,q=0.5]
-
\mathbb{E}[Y_i\mid A_i=A0,\rho=0.85,q=0.5].
]

Negative values favour JEPA advisory warnings. Estimate the marginal effect standardized with equal weights over the five behavior archetypes and three resource families; also report stratum-specific estimates and the unstandardized test-mixture average.

### 6.2 Confirmatory contrasts

1. JEPA advisory (A1) minus reactive UCON-only (A0): primary superiority contrast.
2. JEPA advisory (A1) minus random advisory (A3): predictive targeting contrast.
3. JEPA advisory (A1) minus supervised advisory (A2): non-inferiority contrast, margin +0.02 in denied-action rate (JEPA minus supervised).

Control family-wise error for the two superiority contrasts with Holm's procedure at two-sided family-wise α=0.05. Test non-inferiority separately at one-sided α=0.025. Report effect estimates and confidence intervals regardless of significance.

### 6.3 Secondary outcomes

- Episode-level any-DENY indicator and total DENY count.
- Completion of the family-specific legitimate workflow objective by step 8.
- Protected-state completion and unauthorized-state invariants.
- Number of distinct actions, repeated attempts after DENY, and action changes after warning.
- Warning count, warning rate, and warning-to-DENY precision/recall using the pre-revision proposed action as the contemporaneous target.
- Warning lead time to the first subsequent DENY, where defined.
- Outcomes by behavior archetype, resource family, `rho`, response propensity, and horizon.
- JEPA/supervised predictive metrics reported as diagnostic outcomes, not substitutes for causal utility.

For warning precision, the pre-revision action's formal verdict may be recorded after the prediction is emitted. It must never be queried by the predictor, threshold selector, or agent before the action revision.

## 7. Statistical analysis and power gate

- Primary analysis: intention-to-treat, episode as the independent unit.
- Preserve the randomized strata in estimation; report equal-stratum standardized effects and raw arm means.
- Use a stratified episode-level bootstrap or randomization-inference procedure that resamples/reassigns whole episodes, never individual windows or transitions. Use at least 5,000 replicates/permutations for final intervals and p-values.
- Report seed-specific estimates and across-seed mean/SD. Do not interpret five synthetic seeds as a random sample of real deployment environments.
- Missing or invalid episodes must be reported by arm and reason. No outcome-dependent exclusions. A malformed episode is handled by a predeclared intention-to-treat rule and sensitivity analysis.
- Predeclare the minimum practically relevant effect as an absolute reduction of 0.05 in denied-action rate. Before generating or inspecting confirmatory test outcomes, run a power simulation using only training/validation pilot variance and the planned blocked assignment. Choose sample size to achieve at least 80% power at the corrected primary alpha, with a fixed maximum of 300 episodes per arm per archetype × family × `rho` × `q` × seed stratum. If the maximum cannot achieve the target power, label the confirmatory test underpowered and do not relax the MDE or alpha after looking at test outcomes.
- Report both the ITT effect and a clearly labelled exploratory effect among episodes in which at least one warning was issued. Do not condition the primary estimand on warning receipt or agent compliance.

## 8. Required implementation and validation tests

1. Assignment is episode-level, reproducible, balanced within declared strata, and independent of outcomes.
2. Every episode contains exactly eight transitions and is assigned to exactly one arm/horizon cohort.
3. No episode ID overlaps train, validation, calibration, validation-pilot, and confirmatory-test partitions.
4. Threshold fitting uses calibration scores only and matching decision-position support; no calibration/test label is used for the 90th-percentile trigger.
5. Test thresholds and randomization manifests are immutable before test outcomes are evaluated.
6. E2 inference accepts only current context and learned parameters; future actions, future observations, labels, policy identity, `rho`, arm, warning state, response propensity, episode ID, and decision position are excluded from predictor inputs.
7. Warning response uses only the warning bit, pre-warning proposal, declared action vocabulary, and exogenous response randomness. It never consults the UCON oracle or denial reason.
8. All original and revised proposals pass through the same formal oracle and online gate; oracle/gate agreement is checked at every step.
9. Predictor scores and warnings cannot change UCON decisions for a fixed action/state pair.
10. At `q=0`, warning and no-warning arms generate identical agent proposals under matched policy/randomness; the negative-control test must detect any violation.
11. At `q=1`, every warning invokes the declared revision mechanism, but no test asserts that the revision must be safer.
12. The random-warning arm is independent of labels and model scores and obeys the frozen warning probability.
13. Episode-clustered inference tests detect a deliberately incorrect transition/window-level bootstrap.
14. Instrumented model inference is numerically identical to the frozen production inference path.
15. Fixed-seed runs reproduce assignment, warning, response, transition, and outcome manifests byte-for-byte.

## 9. Interpretation rules and decision gates

- If A1 reduces denied-action burden versus A0 and A3, with no increase in unauthorized-state violations (which must remain zero), this supports predictive warning utility **within this synthetic response model only**.
- If A1 improves over A0 but not A3, the benefit may come from interruption/replanning rather than predictive targeting.
- If A1 and A2 are similar within the non-inferiority margin, do not claim JEPA superiority.
- If A1 fails to improve over A0, do not rescue the claim with AUROC, selected subgroups, or post-hoc thresholds.
- If effects appear only at `q=1`, state that utility depends on strong agent compliance.
- If the `q=0` negative control changes action proposals or outcomes beyond randomization error, stop: the intervention implementation has a leakage or assignment defect.
- If the randomization, gate-invariance, episode-disjointness, or information-boundary tests fail, no utility claim is permitted.
- No result in this synthetic benchmark authorizes replacing, bypassing, or weakening formal UCON enforcement.

## 10. Limitations

The response model is a controlled action-substitution mechanism, not an empirically validated model of LLM-agent behaviour. The five archetypes are hand-designed; `rho` is a scalar mixture parameter; the action vocabulary and policy environment are synthetic. The study cannot establish transfer to real tool-using agents, strategic adaptation, adversarial manipulation, production alert fatigue, or real security incidents. A later external-validity stage would require consented trace data or a separately validated agent-in-the-loop simulator, with independent governance and safety review.
