# G8.4.8.7.5 — Matched recursive state-dynamics control

**Status:** comparator redesign committed; focused and five-seed validation pending. The first risk-only supervised comparator was rejected during scientific audit and its results are diagnostic only.  
**Date:** 19 November 2026.  
**Parent:** corrected G8.4.8.7.4 recursive risk benchmark.

## 1. Research question

Does JEPA's EMA-target latent predictive objective improve recursive future-DENY forecasting over a capacity-near-matched, directly supervised state-dynamics model when both receive only the same initial decision-time context and generate their own future actions?

## 2. Why the first comparator was rejected

The first LinearActionConditionedSupervised control was trained to decode security targets from its latent output. The recursive rollout then reused that output as if it were the next context-state latent. Its action head, however, was trained on latents encoded from observed contexts. This mismatched the learned latent semantics between training and recursive inference. Its multi-step scores therefore cannot support a JEPA-versus-supervised claim.

The old five-seed artifact is retained for auditability, but all its comparative performance conclusions are superseded and must not be cited as valid evidence.

## 3. Corrected models

### J — JEPA E2

- Context and action encoders.
- Action-conditioned latent predictor.
- EMA target encoder for future context.
- Variance-floor regularization.
- Security decoder and past-only action head.
- Latent dimension 12; 852 trainable parameters for the frozen G8.4.8.7 dataset dimensions.

### S — directly supervised state dynamics

LinearSupervisedStateDynamics is a new control with:
- Context and action encoders.
- Action-conditioned latent predictor.
- A decoder trained directly to reconstruct the next observable context in standardized observation space.
- The predicted next context is re-encoded by the same context encoder used by the action head. Thus each recursively generated latent is in the action head's training representation space.
- A security decoder trained on the corresponding next-step security targets.
- No EMA target encoder and no JEPA latent-target objective.
- Latent dimension 8; 776 trainable parameters (91.1% of J's trainable parameter count, within the predeclared 10% capacity tolerance).

The control predicts next context and security state jointly. This avoids treating a security-only latent as a future context representation.

## 4. Shared protocol

- Five seeds: 20261120–20261124.
- Five synthetic behavior archetypes × three security families.
- 300 episodes per cell.
- Train rho {0.20, 0.40, 0.60}; primary untouched test rho=0.85; reverse diagnostic rho=0.05.
- Horizons 1, 2, 4, 8.
- Episode-disjoint train/validation/calibration/test partitions.
- Same training rows, input scalers, action vocabulary, batch size 128, learning rate 0.008, 180 epochs, action-head class, optimizer, maximum epochs, patience, validation checkpoint selection, and calibration procedure.
- Both models receive the same initial context only. Future actions are sampled autoregressively from their own past-only action heads.
- 32 Monte Carlo action rollouts per initial context; common deterministic per-seed/per-horizon random seeds.
- Primary comparison: JEPA minus supervised Brier, paired by complete episode, 2,000 bootstrap replicates per seed/horizon.
- Report parameter counts and the 91.1% capacity ratio explicitly; latent dimensions are not identical.

## 5. Inference and information boundary

At each step:
1. Encode the current context state.
2. Predict an action distribution using only the current predicted latent and known family features.
3. Sample an action.
4. Predict the next state.
5. Re-encode the predicted next context using the same context encoder used by action-head training.
6. Decode DENY risk from that next-state latent.

Neither model may access realized future actions, future observations, security targets, policy identity, rho, episode ID, step, or partition at inference. Future context and security labels are training targets only.

Formal UCON remains the sole authorization authority. Predictions cannot authorize an operation or override DENY.

## 6. Calibration and endpoints

- One action temperature per model, fitted on nominal-support calibration rows only.
- One horizon-specific ridge-Platt risk calibrator per model, using one predeclared step-0 window per calibration episode.
- Horizon-matched training-prevalence baseline.
- Primary endpoint: Brier score for any formal UCON DENY over the next H transitions at rho=0.85.
- Secondary endpoints: AUROC, AUPRC, 10-bin ECE, subgroup metrics, seed variability, action sampling dispersion, calibration diagnostics, parameter counts, optimization steps and runtime.
- rho=0.05 remains a separate reverse-shift diagnostic.

## 7. Acceptance gates

1. Full G8.4 regression suite and focused comparator tests pass.
2. Both model pipelines are deterministic under fixed seeds.
3. Supervised next-context predictions are finite and the recursive latent is re-encoded in the action-head representation space.
4. No future target or metadata enters inference.
5. Calibration is finite and fitted only on nominal-support calibration episodes.
6. Five-seed benchmark completes with datasets, manifests, checksums, subgroup metrics and paired whole-episode bootstrap intervals retained.
7. All archetype/family cells are reported; single-class AUROC is undefined, never imputed.
8. No JEPA advantage is claimed unless paired evidence, seed stability and subgroup behavior support it.

## 8. Interpretation boundary

Even a positive result supports only a JEPA-objective benefit within this synthetic controlled-shift benchmark. It does not establish real-agent transfer, intervention utility, or production authorization assurance.
