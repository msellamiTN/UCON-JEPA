# G8.4.8.7.5 — Matched supervised recursive risk control

**Status:** protocol, implementation, focused tests, and CI workflow committed; CI and full benchmark pending. No performance result is claimed.  
**Date:** 19 November 2026.  
**Parent:** corrected G8.4.8.7.4 recursive risk benchmark.  
**Parent branch:** `research/g8.4.8.7.4-recursive-risk-forecasting`.

## 1. Research question

Does the JEPA predictive-representation objective improve recursive future-DENY forecasting over a deployable, capacity-matched supervised recursive risk predictor when both systems receive only the same initial decision-time context and generate their own future actions?

This is the decisive comparator missing from G8.4.8.7.4. A comparison against the constant training-prevalence baseline alone cannot establish JEPA-specific benefit.

## 2. Models

### J — JEPA E2

Use the corrected G8.4.8.7.4 model:
- context encoder and action encoder;
- latent action-conditioned predictor;
- EMA target encoder on future context;
- variance-floor regularization;
- security decoder;
- past-only action head fitted on model latents.

### S — supervised recursive risk E2

Use the existing `LinearActionConditionedSupervised` control in `jepa_numpy.py`. It has the same context/action encoders, latent dimension, action-conditioned predictor, and security decoder shapes as J, with exactly the same trainable parameter count. It removes the EMA target encoder and latent-prediction/variance objectives; its latent transition is trained directly against the security targets by supervised MSE. Its own latent context encoder is used to fit its own past-only action head.

This is a matched direct-risk-supervision control, not a second JEPA model. At inference, S receives only initial context, its latent state, and sampled actions; it recursively advances the same-shaped latent transition and decodes per-step DENY risk. It never receives realized future context, actions, observations, or labels.

### Capacity and optimization controls

- Both models use latent dimension 12 and identical context/action/predictor/security dimensions.
- Both have exactly equal trainable parameter counts; record the count from each instantiated model.
- Use the same train rows, validation rows, calibration rows, data scalers, action vocabulary, batch size 128, learning rate 0.008, 180 epochs, and initialization seed.
- Match action-head class, optimizer, maximum epochs, patience, validation checkpoint selection, and temperature calibration procedure.
- Use common random numbers for Monte Carlo action sampling where possible, with deterministic per-seed/per-horizon seeds.
- Report actual optimization steps, selected epochs, parameter counts, and runtime. If exact compute matching is not achieved, disclose the mismatch.

## 3. Data and split protocol

Reuse the frozen G8.4.8.7.1 generator and the exact G8.4.8.7.4 seed/split design:
- seeds 20261120–20261124;
- five archetypes × three security families;
- 300 episodes per cell;
- train rho {0.20, 0.40, 0.60};
- primary untouched test rho=0.85;
- reverse diagnostic rho=0.05;
- horizons 1, 2, 4, 8;
- episode-disjoint train/validation/calibration/test partitions.

No test rho, test label, policy identity, episode metadata, or future observation may enter model fitting, checkpoint selection, action calibration, or risk calibration.

## 4. Inference contract

Both J and S must implement the same callable E2 signature: initial decision-time context, horizon, Monte Carlo sample count, and random seed. The rollout:
1. encodes the initial context;
2. predicts an action distribution from the current predicted latent and known family features;
3. samples an action;
4. advances the latent with the action-conditioned transition;
5. decodes per-step DENY risk;
6. aggregates horizon risk as one minus the product of per-step survival probabilities.

Neither model may access realized future actions, future observations, security targets, policy ID, rho, episode ID, step, or partition at inference. Add target-mutation and signature-boundary tests for both models.

## 5. Calibration and baselines

- Fit one action temperature per model on nominal-support calibration rows only.
- Fit one horizon-specific Platt calibrator per model using exactly one predeclared step-0 window per calibration episode.
- Use the corrected standardized-logit ridge Platt routine from G8.4.8.7.4.
- Retain calibration coefficients, objective diagnostics, class counts, and calibration-episode counts.
- Include the horizon-matched training-prevalence baseline.
- Retain the G8.4.8.7.4 privileged E1 results only as an explicitly non-deployable information reference; E1 is not a fair model comparator.

## 6. Endpoints and statistical comparison

Primary endpoint: Brier score for the probability of at least one formal UCON DENY over the next H transitions at rho=0.85.

Secondary endpoints:
- AUROC, AUPRC, 10-bin ECE;
- per-archetype/family metrics and target prevalence;
- seed-level metrics and variability;
- action sampling dispersion and calibration diagnostics;
- model parameter counts, training steps, and runtime.

Primary contrast: JEPA E2 minus supervised E2 Brier, paired by complete episode. Negative favors JEPA. Use 2,000 paired whole-episode bootstrap replicates per seed/horizon; report each seed's interval and the across-seed summary without treating overlapping windows as independent.

Report rho=0.05 separately as a reverse-shift diagnostic. Do not pool it into the primary estimand.

## 7. Acceptance gates

1. Full G8.4 regressions and focused comparator tests pass.
2. Both model training pipelines are deterministic under fixed seeds.
3. Parameter-count and optimization-budget comparison is explicit.
4. Inference signatures exclude all future targets and metadata.
5. Calibration is finite, stable, and fit only on calibration episodes.
6. Five-seed full benchmark completes with retained datasets, configs, manifests, checksums, metrics, and bootstrap intervals.
7. All archetype/family cells are reported; single-class AUROC is marked undefined, never imputed.
8. No JEPA advantage is claimed unless the primary paired episode-bootstrap evidence supports it and subgroup reversals are adequately characterized.

## 8. Interpretation boundary

A positive result would support a JEPA-objective benefit only within this synthetic controlled-shift benchmark and under the stated matched architecture/training budget. It would not establish real-agent transfer, intervention utility, or production authorization assurance.

Formal UCON remains the sole authorization authority. Predictive models cannot authorize operations or override DENY.
