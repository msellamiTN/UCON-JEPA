## 3. Proof review observations

1. The safety proofs depend on the exact transition relation. If an implementation permits an external effect without the Accept guard, the theorem does not apply.
2. The revocation theorem concerns the effective-revocation linearization point, not the time an administrator submits a revocation request.
3. The policy theorem uses strict version equality. Any compatibility rule requires a separate proof.
4. The commit theorem proves protocol ordering, not the truth of the receipt. Receipt provenance and verifier correctness remain assumptions.
5. JEPA non-authority is structural in the model. A deployed predictor must also lack independent credentials and direct tool routes.
6. The model does not yet prove resource serializability, asynchronous cancellation, durable recovery, or liveness.
7. The TLC exploration is finite and bounded by the two-invocation configuration. It is not an unbounded proof.
8. Mutation controls demonstrate sensitivity to four selected defect classes; they do not prove completeness of the threat model.

The next research stage should select one concrete reference adapter with conditional mutation semantics (for example, an API supporting ETag/CAS), implement gateway-only credentials, and discharge O-G6-01 through O-G6-06 against that adapter before expanding to asynchronous and weakly observable tools.
